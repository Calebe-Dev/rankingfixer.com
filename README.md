# rankingfixer.com

English-language site for technical SEO fixing services: audits, Core Web Vitals, indexing issues and site migrations.

Planned stack, the same as [calebearaujo.com.br](https://calebearaujo.com.br): SvelteKit (prerendered static pages, no client-side JavaScript), deployed as a Cloudflare Worker.

Maintained by [Calebe Araujo](https://calebearaujo.com.br).
